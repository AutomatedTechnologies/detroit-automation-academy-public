Read this before you run it

  • This build incorporates the Academy's tranche-1 security remediation. F-01: bounded SSID string handling (strlcpy/strlcat) with a 32-octet SSID cap at file ingestion. F-02: the bundled polarssl library is removed — MD4/MD5/SHA1 and HMAC now use the system CommonCrypto. F-11: legacy session files are unarchived through an NSSecureCoding class allowlist on the 10.13-floor API. F-13: the capture-device permission step uses mode 0660 (was 0777) and restores 0600 immediately after the device opens.
  • HTTP crash reporter REMOVED (finding F-04). The built-in crash reporter that could send crash reports over plain HTTP to a third-party endpoint is deleted in this build, together with its launch-time collection. Verified in the packaged binary: no crash-report code or endpoint strings remain.
  • Dead map services REMOVED; updater material purged (U1). The map-download feature and all seven of its defunct third-party endpoints (terraserver, Expedia, map24, tiger.census.gov, street-directory) are deleted, as is the orphaned updater public key. Verified absent from the packaged binary. Local map images and saved sessions are unaffected.
  • Runtime status — stated exactly. The KisMac Discover engine lineage was runtime-verified on macOS High Sierra on 2026-11-07: the previous master-lineage test build (test-build-14) was launched on a real MacBook Air and scanned live networks. This remediated build is CI-built and awaits its own rig run — it has not yet been run on hardware by the Academy.
  • One privileged-helper item remains open (findings F-12/F-03). The audit's privileged-helper finding is not yet remediated in this lineage: the replacement — a fixed-operation, zero-argument helper on the ChmodBPF model — is designed and filed as remediation tranche 2. Until it lands, the /dev/bpf permission step still runs through the audited executor, at the tightened 0660 with immediate restore described above.
  • Test on High Sierra, preferably not on a network you care about. Use a test machine and an isolated network.

KisMac is a Wi-Fi stumbler and scanner originally by Michael Roßberg and contributors, maintained here as part of the Academy's program to keep useful macOS software building and running on High Sierra. Questions: detroit@muse.ai.
