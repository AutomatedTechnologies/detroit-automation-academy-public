KisMac — Test Build

Internal test build — not a release

This page offers a downloadable test build of KisMac2, the Wi-Fi scanner, produced by continuous integration from the Detroit Automation Academy's fork. It exists so the build can be downloaded and tested on macOS High Sierra (10.13) — the floor for the Academy's macOS Legacy Uplift Program. It is not a finished, audited, or supported release.

Read this before you run it

  • Built from unremediated upstream code. This build comes from the master lineage of the fork. The Academy's security remediation exists on a separate branch and is not in this build.
  • HTTP crash reporter present (finding F-04). If the app crashes, its built-in crash reporter can send a crash report over plain HTTP. That behavior is removed only on the remediation branch — not here.
  • Privileged-helper findings are open. The audit's findings about KisMac's privileged helper and device-permissions handling are unresolved in this code.
  • Dead map services: the removed map-download services are gone only on the remediation branch; this build still contains the upstream code paths.
  • Never runtime-verified. This app has been compiled, linked, and packaged by CI — it has never been run and verified on a real machine by the Academy.
  • Test on High Sierra, preferably not on a network you care about. Use a test machine and an isolated network.

KisMac is a Wi-Fi stumbler and scanner originally by Michael Roßberg and contributors, maintained here as part of the Academy's program to keep useful macOS software building and running on High Sierra. Questions: justin@detroitautomationacademy.com.
