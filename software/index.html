Academy Software

The Detroit Automation Academy maintains useful open-source Mac software that its original authors no longer do. Each application offered for download is audited for security issues, remediated, branded, and verified running on macOS High Sierra (10.13) — the floor for every Academy build — on real hardware before it is offered. Applications still in testing carry their true status in the catalog and are not offered as verified downloads. Every application is free, ships with its full source under its original open-source license, and contacts no update, crash-report, or telemetry service the Academy does not operate.

Statuses below state exactly where each application stands. Nothing is listed as available until a verified build exists.
