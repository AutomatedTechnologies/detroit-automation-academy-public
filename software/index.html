Software · macOS Legacy Uplift Program

Academy Software

The Detroit Automation Academy maintains useful open-source Mac software that its original authors no longer do. Each application is audited for security issues, remediated, branded, and verified running on macOS High Sierra (10.13) — the floor for every Academy build — before anything is offered for download. Every application is free, ships with its full source under its original open-source license, and contacts no update, crash-report, or telemetry service the Academy does not operate.

Statuses below state exactly where each application stands. Nothing is listed as available until a verified build exists.

Test build available

KisMac — Wi-Fi scanner

A Wi-Fi stumbler and scanner (GPL-2.0), archived upstream since 2018. The Academy fork builds again: an internal test build is available for High Sierra, and the engine was verified running a live scan on a real High Sierra machine on November 7, 2026. A remediated test build — with the audit's security fixes incorporated — is in preparation.

KisMac test build page →

Staged test build available

Switchboard — network utility

The Academy's own network utility — Wi-Fi discovery (the KisMac engine), Ping, Netstat, Traceroute and Speed Test diagnostics, a read-only view of Apple AirPort base-station configuration, and a local journal, in one application. A staged internal test build was CI-built on November 7, 2026; it has not yet been verified on a High Sierra machine.

Staged build staged-v1-1 (GitHub prerelease) →

Test build available

Distro — the Academy store for High Sierra

A native application store that delivers Academy-maintained software to High Sierra machines, with every download verified against a published SHA-256 hash before install. Its catalog is live. An MVP test build of Distro itself (distro-test-1) was CI-built on November 8, 2026; it has not yet been verified on a High Sierra machine. Publisher: Detroit Automation Academy.

Distro test build distro-test-1 (GitHub prerelease) →

In development

Spectacle — window manager

Keyboard-driven window management (MIT). Security audit complete — no critical or high findings — and its updater has been repointed to Academy infrastructure. No build is available yet.

In development

MacDown — Markdown editor

A Markdown editor (MIT). Security audit complete; a rendering-engine migration to WKWebView is designed and under way. No build is available yet.

In development

Sequel Pro — database client

A MySQL database client (MIT). Security audit complete; its end-of-life bundled database library is being replaced with MariaDB Connector/C so it can connect to modern servers. No build is available yet.

In development

SoundDeck — audio editor

An audio editor built on Audacity with libVLC playback and conversion (GPL). License review passed and versions are pinned to the last releases that run on High Sierra. No build is available yet.

Queued

AutoDMG — system image builder

Builds deployable macOS system images (Apache-2.0). Selected for uplift; work has not begun. No build is available.
