iOS Shortcut recipe — “DAA Publish” (no Worker needed)

One-time: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → new token, repo smit4786/detroit-automation-academy-public, Contents: Read and write. Save it in your password manager.

  1. Text = your token → variable PAT.
  2. Get Contents of URL GET https://api.github.com/repos/smit4786/detroit-automation-academy-public/contents/live.json, header Authorization: Bearer «PAT». Save sha → FileSHA; base64-decode content → Current (today's live.json, used for defaults).
  3. Ask for Input for announcement text / link / link label / the 3 stat numbers + labels — each with its current value as the default answer, so tapping through keeps everything.
  4. Escape each answer: Replace Text \ → \\, then " → \" (literal, not regex).
  5. Text the JSON {"announcement":{"text":"…","link":"…","linkLabel":"…"},"stats":[{"num":"…","label":"…"},…]} → Base64 Encode → FileB64.
  6. Get Contents of URL PUT same URL, JSON body {"message":"Update live.json from iOS Shortcut","content":"«FileB64»","sha":"«FileSHA»"}.
  7. Show Result “Published — live in ~2 min.” A 409 means the file changed since you fetched it; run again.

Lock the Shortcuts app behind Face ID — the token lives inside the shortcut. Full step-by-step: daa-owner-layer/ios-shortcut-recipe.md in your files.
