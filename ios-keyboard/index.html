Forge Keyboard

A keyboard that types what you type. Nothing you type is ever replaced without your tap — the candidate bar offers up to three suggestions, and a suggestion is inserted only when you tap it. No key flicks. Your vocabulary built in: infrastructure, Jamf, macOS, endpoint, Detroit, Southfield, AutomatedTechnologies, GitLab, Terraform, YAML.

The keyboard requests no Full Access and does no networking. Keystrokes stay on the device.

Download the Xcode project (.zip)

Install it (Mac, Xcode 16 — free provisioning, $0)

  1. Unzip ForgeKeyboard.zip on the Mac.
  2. Open ForgeKeyboard.xcodeproj in Xcode.
  3. Xcode → Settings → Accounts → sign in with your Apple ID (once; Xcode creates the free Personal Team).
  4. Select the ForgeKeyboard target → Signing & Capabilities → "Automatically manage signing" → Team: your Personal Team. Do the same for the ForgeKeyboardKeyboard target if Xcode asks.
  5. Connect the iPad, select it as the run destination, Run (⌘R).
  6. If prompted on the iPad: Settings → General → VPN & Device Management → the developer profile → Trust.
  7. Settings → General → Keyboard → Keyboards → Add New Keyboard… → Forge Keyboard. Then hold the globe key in any app and pick Forge Keyboard.

Requirements. iPhone or iPad running iOS 17 or later; a Mac with Xcode 16 for the one compile-and-sign step.

iOS installs only builds whose signature chains to Apple, so the final step happens on the Mac: free provisioning signs with the owner's own Apple ID at no cost. The free profile expires after 7 days; reinstall from Xcode the same way to renew it.
