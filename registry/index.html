Query the snapshot

The canned queries below run, in your browser, against the verified snapshot — the same predicates the registry's own census tools run. The SQL box accepts a single read-only SELECT statement.

Catalog state — catalog_state ⋈ apps ⋈ builds

SELECT a.id AS app, cs.status, b.tag AS current_build
FROM catalog_state cs
JOIN apps a ON a.id = cs.app_id
JOIN builds b ON b.id = cs.current_build_id
ORDER BY a.sort_order;

Conformance summary — the conformance view + v_unverified_count

SELECT attestation_state, COUNT(*) AS apps FROM conformance
GROUP BY attestation_state;
SELECT scope, unverified FROM v_unverified_count WHERE scope = 'ESTATE';

Domain census — page_checks (Loop 5 predicates)

SELECT (SELECT COUNT(*) FROM page_checks) AS population,
       (SELECT COUNT(*) FROM page_checks WHERE in_sitemap = 0) AS not_in_sitemap,
       (SELECT COUNT(*) FROM page_checks WHERE design_observed = 'standalone-inline') AS standalone_inline,
       (SELECT COUNT(*) FROM page_checks WHERE stamp_present = 1) AS stamped,
       (SELECT COUNT(*) FROM page_checks WHERE ip_notice_class = 'full') AS ip_full;

Claims census — claims (HF-04 predicates)

SELECT COUNT(*) AS claims,
       SUM(evidence_ref IS NOT NULL) AS traced,
       COUNT(*) - SUM(evidence_ref IS NOT NULL) AS untraced
FROM claims;
